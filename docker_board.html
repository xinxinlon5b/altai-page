五、学习次第（怎么跟着学 Docker）
1️⃣ 理解概念：容器=标准集装箱（代码+环境打包，任何电脑都能跑）
2️⃣ 看结构：altai-docker/ 目录 = 项目骨架
3️⃣ 看入口：run.py --self-check（自检 = 启动前的体检）
4️⃣ 看 Dockerfile：FROM python:3.11 → 装依赖 → 复制代码 → 健康检查
5️⃣ 看 compose：docker compose up -d（一键启动 = 一条命令）
6️⃣ 实操验证：docker compose ps（healthy 绿）= 第一步成功
7️⃣ 改配置：config/local.yaml（send_mode）→ 重启生效
8️⃣ 备份数据：data/ 目录直接拷（SQLite 文件）
